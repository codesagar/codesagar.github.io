# Sagar Patel

Personal website: https://codesagar.github.io/

Static HTML, CSS and JavaScript. Built with `node scripts/build.mjs` and published through GitHub Pages. Changes pushed to `main` deploy automatically.

- `site/fieldguide.html`: page structure and introductory copy.
- `site/assets/fieldguide-content.js`: career, projects, publications and education.
- `site/assets/fieldguide.css`: styles and responsive layouts.
- `site/assets/carousel.js`: photo carousels.

Run `npm run preview` to preview locally. The build publishes only `dist/`.
